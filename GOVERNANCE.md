# Governance

## Project Governance

WarpFS (Hilo) is maintained by Alexis Okuwa (@wojons). 

## Decision Making

- **Maintainer**: Has final say on all technical decisions, merge rights, and release management.
- **Contributors**: Propose changes via pull requests. All PRs require CI to pass and maintainer approval before merge.

## Code of Conduct

This project adheres to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). Violations should be reported to the maintainer.

## Security

See [SECURITY.md](SECURITY.md) for the vulnerability reporting process.

## Roadmap

The project roadmap is managed through `.coding-hermes/board/tasks.jsonl` and the coding-hermes autonomous development fleet.
